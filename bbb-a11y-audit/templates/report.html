Auditoria de acessibilidade

Resumo

Conformidade WCAG 2.2 AA

Cada diretriz é uma fase de trabalho. Ela está concluída quando todos os seus critérios passaram ou não se aplicam. Cada critério diz quem o verificou: a ferramenta, o agente (lendo código e prints) ou uma pessoa.

Roteiros para uma pessoa executar: critérios que só uma pessoa consegue decidir e confirmações com leitor de tela de verdade.
